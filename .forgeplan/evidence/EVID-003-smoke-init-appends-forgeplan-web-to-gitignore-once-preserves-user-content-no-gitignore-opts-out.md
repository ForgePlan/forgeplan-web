## Measurement

Three smoke runs against fresh scratch directories:

1. **Existing `.gitignore` + first init**: pre-write
   `existing user gitignore\nnode_modules/\n`, run `init -y`, inspect file.
2. **Same dir + second init `--force`**: re-run `init -y --force`, count
   `.forgeplan-web/?` matches per line.
3. **Existing `.gitignore` + `--no-gitignore`**: pre-write any content,
   run `init -y --no-gitignore`, file must be byte-identical.
4. **Missing `.gitignore` + `--no-gitignore`**: file must remain absent.
5. **Missing `.gitignore` + default**: file must be created with
   marker comment + `.forgeplan-web/` only.

Idempotency check baked into `scripts/smoke.mjs` (CI matrix coverage):
- writes `# pre-existing user line\nnode_modules/\n` before init,
- runs `init -y` then `init -y --force`,
- counts matches of `^[ \t]*\.forgeplan-web\/?[ \t]*$` per line — must
  equal 1 after each run, must include the pre-existing user line.

Bug surfaced + fixed during the same change: `dist/node_modules/.bin/`
contained absolute symlinks pointing into the publisher's repo path
(`acorn`, `svelte-kit`). On a second `init --force` run, `cpSync`
choked with `ERR_FS_CP_EINVAL` trying to copy a symlink onto itself.
On a real user's machine those symlinks would have been dangling.
`scripts/build.mjs` now `pruneSymlinks(dist)` after the copy step
(removes `node_modules/.bin/` and any stray symlinks). Rule 21 is
preserved at the published-artifact boundary.

```

[smoke] init -y --force (run 2 — must be idempotent)
→ updating .../.forgeplan-web
[smoke] gitignore: still 1 match after second init (idempotent)
[smoke] /api/health: ok (project=shim)

```

Manual checks (additional scratch dirs):
- `init -y --no-gitignore` against existing `.gitignore` → file
  byte-identical: ✅.
- `init -y --no-gitignore` without `.gitignore` → file not created: ✅.
- Default `init -y` without `.gitignore` → created with body
  `# generated by @forgeplan/web init\n.forgeplan-web/\n`: ✅.
- `find dist -type l` → empty (symlinks pruned): ✅.

## Interpretation

ADR-001 implementation behaves to spec across all five scenarios. Rule
20 narrowed scope (`.gitignore` append-only) is enforceable: the only
host write outside `.forgeplan-web/` is the bounded append, and it is
idempotent + opt-out. The discovered absolute-symlink bug in `dist/`
was a latent rule-21 violation triggered by the `init --force` retry
path; fixed by pruning `node_modules/.bin/` during the build pipeline.

## Congruence Level Justification

CL3 — same-context: every assertion is taken against the exact `bin/`,
`dist/`, and `scripts/` artifacts the published package ships. The
smoke harness is the same one CI runs on the matrix. Penalty 0.0.
